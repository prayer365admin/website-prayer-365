# 28. Glossary

> Part of: Admin Guidebook v1.0

## What this page is for

The words this book uses, in the meaning the platform uses them. Read it once; come back when a term in a chapter is unclear.

## Who can use it

Everyone. No permissions are needed to read a glossary.

## Before you start

Nothing. Terms are alphabetical inside each group.

## Organisation

| Term         | Meaning                                                       |
| ------------ | ------------------------------------------------------------- |
| Global root  | The top of the organization tree; every country sits under it |
| Country      | First level under the global root, for example Estonia        |
| Diocese      | Second level, for example Estonia Diocese                     |
| Deanery      | Third level, for example Tallinn Deanery                      |
| Church       | The parish: the unit that has a public page                   |
| Placement    | A church's country, diocese and deanery; fixed after creation |
| Jurisdiction | The organization node a staff account is bound to             |

## People

| Term            | Meaning                                                                     |
| --------------- | --------------------------------------------------------------------------- |
| Staff account   | A dashboard login created in chapter 12                                     |
| Customer        | A public account created on the website or app (chapter 14)                 |
| Pastor          | A person record tied to a church, shown publicly and used as a prayer voice |
| Request reader  | A staff role that may read prayer and pastoral requests                     |
| Private request | A request visible only to accounts with the private grant                   |
| Role            | A named set of permissions (chapter 13)                                     |
| Permission      | One action on one subject, for example `Prayer Prayer → Create Any`         |
| Scope           | The part of the platform an account can see                                 |

## Content

| Term                             | Meaning                                                           |
| -------------------------------- | ----------------------------------------------------------------- |
| Prayer                           | Title, text, pastor, language and audio; has versions             |
| Prayer version                   | One saved state of a prayer's text; a published version is locked |
| Audio asset                      | The generated recording attached to a prayer version              |
| Voice profile                    | The model of a pastor's voice, submitted and reviewed             |
| Consent / authorization evidence | The signed document that allows the voice model                   |
| Statement: READY                 | The voice can be used to generate prayer audio                    |
| Publish                          | Make content visible to visitors                                  |
| Schedule publication             | Publish automatically at a future moment                          |
| Draft                            | Saved content that is not public                                  |
| Announcement                     | Short church news for the app                                     |
| Event                            | A dated church activity with an optional registration link        |
| Gallery                          | The public image set of a church                                  |
| Hero image                       | The large image at the top of a church page                       |
| Cover image                      | The card image of a church                                        |

## Money and messaging

| Term               | Meaning                                                        |
| ------------------ | -------------------------------------------------------------- |
| Provider-confirmed | Confirmed by the payment provider; only these count in reports |
| Recurring donation | A repeating subscription                                       |
| Monthly summary    | Gross, refunded and net per month and currency                 |
| Notification rule  | A platform rule that decides when a message is sent            |
| Reminder offset    | How long before an event a reminder fires                      |
| Channel            | Push notification, email, or both                              |

## Technical words used in messages

| Term      | Meaning in plain words                                           |
| --------- | ---------------------------------------------------------------- |
| Approval  | A state that makes a church public                               |
| Suspended | Temporarily removed from public view, data kept                  |
| Archived  | Permanently removed from public view, data kept                  |
| Rebuild   | Regenerating the app and its styles before it runs               |
| Slug      | The last part of a public address, for example `st-johns-church` |

## What changes on the website

Nothing. A glossary is a reference page.

## Common problems

| Confusion                                       | Clarification                                                                      |
| ----------------------------------------------- | ---------------------------------------------------------------------------------- |
| "User" versus "customer"                        | User = staff (chapter 12); customer = public account (chapter 14)                  |
| "Publish" versus "save"                         | Save keeps your work; publish makes it visible                                     |
| "Approved" church versus "approved" prayer text | Church approval makes the church public; prayer text approval unlocks audio        |
| "Voice approved" versus "voice ready"           | Approval is the admin decision; ready means the provider can generate audio        |
| "Analytics"                                     | The placeholder screen in chapter 25 is not the same as the counters in chapter 04 |
