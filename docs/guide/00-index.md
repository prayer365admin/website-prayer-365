## How to read a chapter

Every chapter has the same shape, so you can jump to the part you need:

| Section                     | What it answers                              |
| --------------------------- | -------------------------------------------- |
| What this page is for       | One paragraph, plain words                   |
| Who can use it              | Which roles see this screen                  |
| Before you start            | What must be true before the steps work      |
| Step by step                | Numbered actions, each with a screenshot     |
| Fields explained            | What each field means, and if it is required |
| What changes on the website | Where the result appears for visitors        |
| Common problems             | Symptom → cause → fix                        |

## Screenshot legend

| Mark                     | Meaning                                     |
| ------------------------ | ------------------------------------------- |
| Red box                  | The part of the screen the step talks about |
| Red circle with a number | The order of the steps in that screenshot   |

All screenshots in this book come from a demo database with fake names, fake churches and fake donations. Nothing in them is real customer data.
